# ML Workspace

This folder is for the project's predictive ML work.

## Planned models

- No-show prediction
- Crowd prediction

## Suggested lifecycle

```text
Approved dataset
 -> cleaning
 -> feature engineering
 -> train/validation/test split
 -> baseline
 -> model training
 -> evaluation
 -> error analysis
 -> model version
 -> backend prediction service
```

Do not commit private medical data or fabricated datasets.

The actual algorithm, features and metrics must be selected and documented after the team obtains an appropriate dataset.
